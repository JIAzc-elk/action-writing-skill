# 炼化·工艺 词库

覆盖：炼制 / 养育培育 / 改良升华 / 催动使用 / 失控反噬

> 适用于任何有"制造/培养/改造"系统的题材：炼丹、炼器、培育异兽、蛊虫、炼金、机甲制造等。  
> 不限于特定题材，不用时不调用。

---

## 炼（制造/转化）

| 候选词 | 含义 | 适用 |
|------|------|------|
| 炼制 | 通过工艺制成 | 通用，最常用 |
| 炼化 | 炼制并转化为可用状态 | 玄幻、修真 |
| 合炼 | 多种材料合并炼制 | 复合配方 |
| 祭炼 | 以特殊手段炼制（含仪式感） | 高阶炼制 |
| 炼成 | 炼制完成 | 结果词 |
| 提炼 | 从粗糙材料中提取精华 | 精炼过程 |
| 萃取 | 精确提取特定成分 | 丹药、毒素 |
| 熔炼 | 高温融化后重塑 | 炼器 |
| 铸造 | 熔化后铸入模具 | 器物 |
| 锻造 | 锻打成型 | 兵器 |

## 养（培育/维护）

| 候选词 | 含义 |
|------|------|
| 喂养 | 提供食物维持 |
| 豢养 | 长期饲养（含掌控关系） |
| 温养 | 以温和方式持续滋养 |
| 培育 | 有目的地培养成长 |
| 催熟 | 加速成熟 |
| 繁衍 | 繁殖增殖 |
| 孵化 | 从卵/种子中生出 |
| 驯化 | 使之受控 |

---

## 改（改造/优化）

| 候选词 | 含义 |
|------|------|
| 改良 | 在原有基础上优化 |
| 改造 | 结构性改变 |
| 增添 | 添加新属性 |
| 删减 | 去除部分属性 |
| 浓缩 | 压缩提高密度 |
| 升华 | 质的提升 |
| 淬炼 | 反复锻炼强化 |
| 蜕变 | 质变 |
| 进化 | 自然或引导的提升 |

## 用（激发使用）

| 候选词 | 含义 |
|------|------|
| 催动 | 推动运转（最通用，最高频） |
| 催发 | 触发启动 |
| 动用 | 调取使用 |
| 发动 | 启动 |
| 祭出 | 正式取出使用（带仪式感） |
| 激活 | 使处于激活状态 |
| 引爆 | 触发爆发效果 |
| 释放 | 解除封印或储存 |

---

## 果（结果/失控）

| 候选词 | 含义 |
|------|------|
| 反噬 | 效果反过来伤害使用者 |
| 失控 | 脱离掌控 |
| 暴走 | 失控后激烈运转 |
| 溃散 | 结构崩塌消散 |
| 炸炉 | 炼制失败，爆炸 |
| 废了 | 彻底损坏无法使用 |
| 成品 | 炼制成功 |
| 残次品 | 有缺陷的成品 |
| 极品 | 超出预期的成品 |

## 写法说明

**炼制过程写代价，不写成功感**：
> ❌ 他成功地炼制出了一枚丹药。  
> ✅ 火候三次断了又续，最后一枚成了，另外两枚化为灰烬。

**改造写对比**：
> 改良之前：感应范围三十步。改良后：七十步，且穿墙不衰减。

**失控写节奏感**：
> 那东西在他掌心突然烫了起来。他猛地察觉不对，来不及了。
