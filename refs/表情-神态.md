# 表情·神态·身体细部 词库

覆盖：面部 / 眼部 / 头颈躯干 / 手部细部 / 整体气态

> 细部动作是控制节奏的主力，也是给心理活动一个物理落点的工具。  
> 蛊真人几乎每段都用一个细部动作起句，避免空转的内心戏。

---

## 面部

| 候选词 | 表现 | 情绪倾向 |
|------|------|---------|
| 皱眉 | 眉头收紧 | 困惑、不满、疼痛 |
| 挑眉 | 单侧或双侧扬起 | 意外、讽刺、质疑 |
| 脸色微变 | 细微变化 | 克制的震动 |
| 面色如常 | 没有变化 | 高手感、隐藏情绪 |
| 神色一沉 | 整体下沉 | 变得严肃或愤怒 |
| 冷笑 | 轻蔑的笑 | 嘲讽、不屑 |
| 嗤笑 | 从鼻腔发出的笑 | 轻蔑 |
| 咧嘴 | 嘴角拉开 | 嚣张、粗犷的笑 |
| 咬牙 | 牙关咬紧 | 愤怒、克制、痛苦 |
| 动容 | 表情出现变化 | 受到触动 |
| 凛然 | 肃然、冷峻 | 威严、危险感受到 |

---

## 眼部

| 候选词 | 特征 | 情绪倾向 |
|------|------|---------|
| 眯眼 | 眼睛微闭 | 审视、危险、阳光刺激 |
| 瞳孔一缩 | 瞬间反应 | 惊讶、危险 |
| 眼神一凝 | 目光聚焦 | 警觉、发现 |
| 目光闪动 | 眼神变化 | 心思变动 |
| 目光一沉 | 向下或变深 | 变得危险 |
| 垂眸 | 低下视线 | 克制、顺从、隐藏 |
| 抬眼 | 视线上移 | 迎接、挑战 |
| 闭眼 | 合上眼睛 | 感受、放弃、死亡前 |

---

## 头颈

| 候选词 | 幅度 | 情绪倾向 |
|------|------|---------|
| 侧头 | 小 | 疑惑、好奇 |
| 偏头 | 小 | 轻巧、玩味 |
| 低头 | 中 | 顺从、隐藏表情 |
| 抬头 | 中 | 迎接、挑战 |
| 仰头 | 大 | 大笑、傲慢 |
| 垂首 | 中 | 恭敬、受击 |
| 颔首 | 小 | 认可、礼貌 |
| 摇头 | 中 | 否定、无奈 |
| 点头 | 小 | 肯定 |

---

## 躯干 / 整体姿态

| 候选词 | 特征 | 情绪倾向 |
|------|------|---------|
| 负手 | 双手背在身后 | 从容、高手感、等待 |
| 拱手 | 双手叠握于胸前 | 礼貌、武侠正式礼节 |
| 抱拳 | 一手握拳另手包住 | 武林礼节 |
| 挺身 | 腰背挺直 | 迎接挑战、自信 |
| 躬身 | 上身前倾弯腰 | 恭敬、受伤 |
| 顿了顿 | 动作停一下 | 迟疑、克制 |
| 后退半步 | 极小位移 | 警觉、被震慑 |
| 上前一步 | 极小位移 | 施压、迎上 |
| 肩膀一沉 | 下压 | 放松或受击 |

---

## 手部细部（作为标点和节奏器）

| 候选词 | 功能 |
|------|------|
| 抬手 | 准备动作，开启新动作序列 |
| 扬手 | 轻巧、随意的抬手 |
| 挥手 | 结束或示意 |
| 摆手 | 否定、拒绝 |
| 伸手 | 朝目标延伸 |
| 探手 | 谨慎地伸出 |
| 负手 | 收回，转为静态 |
| 抄手 | 两手交叉 |
| 屈指一弹 | 轻巧发动 |
| 五指张开 | 释放范围效果 |
| 握拳 | 收紧，准备或克制 |
| 攥紧 | 持续用力 |
| 松开 | 放弃或完成 |

---

## 气态（整体印象词，少用，用则有效）

| 候选词 | 传达信息 |
|------|---------|
| 忌惮 | 对方让他产生顾虑 |
| 凛然 | 肃然感受到危险或威严 |
| 漫不经心 | 表面随意（可能是掩护） |
| 波澜不惊 | 完全没有反应 |
