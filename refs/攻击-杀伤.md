# 攻击·杀伤 词库

覆盖：近身劈砍 / 钝击爪牙 / 远程释放 / 命中结果

---

## 核心原则

攻击词的选择决定冲突的**节奏快慢**和**力量感**。  
蛊真人最常用**动补式**：斩落、轰碎、震退、洞穿——一个词同时给动作和结果，不写第二句解释。

---

## 近身劈砍

| 候选词 | 动作特征 | 力度 | 情绪倾向 |
|------|---------|------|---------|
| 斩 | 横向切断 | 重 | 决绝、干净 |
| 劈 | 垂直向下 | 重 | 粗暴、威压 |
| 削 | 斜向薄切 | 中 | 精准、冷静 |
| 撩 | 由下向上 | 中 | 变招、灵活 |
| 扫 | 大弧度横扫 | 重 | 压制、范围攻击 |
| 挑 | 由下向上刺 | 中 | 轻巧、变招 |
| 刺 | 直线穿入 | 重 | 冷酷、致命 |
| 戳 | 点状穿刺 | 中 | 精确、烦躁 |
| 贯 | 完全穿透 | 极重 | 绝杀感 |

## 钝击 / 爪牙

| 候选词 | 动作特征 | 情绪/效果 |
|------|---------|---------|
| 轰 | 重力冲击 | 震撼感、玄幻常用 |
| 砸 | 向下击落 | 暴力、原始 |
| 撞 | 整体冲入 | 蛮力、直接 |
| 崩 | 爆发式冲击 | 瞬间爆发 |
| 抡 | 大弧度挥舞 | 蛮力 |
| 鞭 | 软质物打击 | 凌厉 |
| 碾 | 持续压过 | 压迫、蔑视 |
| 绞 | 旋转撕扯 | 残忍 |
| 噬 | 牙齿咬入 | 野兽感 |
| 剜 | 挖出 | 残忍、精准 |

|------|---------|---------|

| 打出 | 主动发射 | 法术、掌力 |

| 迸射 | 四散喷出 | 爆炸、群体 |

| 蔓延 | 缓慢扩散 | 毒、腐蚀类 |
| 席卷 | 大范围横扫 | 风、火类 |
| 倾泻 | 大量落下 | 洪水、剑雨 |
| 泼洒 | 散乱覆盖 | 液态蛊毒 |

## 命中结果（动补式，最省字）

| 动补词 | 结果 |
|------|------|
| 斩落 | 切断并落下 |
| 轰碎 | 冲击后碎裂 |
| 震退 | 震动后退开 |
| 洞穿 | 穿孔而过 |
| 碾平 | 压碎铺平 |
| 击溃 | 打散防御 |
| 破防 | 穿透防御层 |
| 撕开 | 强行扯裂 |
| 崩断 | 爆裂断开 |
| 削去 | 切掉一部分 |

---

## 强度三档

同一场戏动词要递进，不能一直用最重的。

| 轻 | 中 | 重 |
|---|---|---|
| 碰、触、掠、擦 | 拍、击、撞、推 | 轰、碾、崩、贯、碾碎 |
