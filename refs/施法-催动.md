# 施法·催动 词库

覆盖：催发 / 手法动作 / 资源流转 / 效果落地 / 蛊虫驱使

> 玄幻写作的核心词库。法术和蛊虫的动词选择直接决定"战斗感"是否成立。

---

## 催发（发动法术/蛊虫的起手词）

| 候选词 | 特征 | 适用场景 |
|------|------|---------|
| 催动 | 主动推动运转 | 最通用，蛊真人高频 |
| 催发 | 触发使之启动 | 法阵、机关 |
| 激发 | 瞬间触发 | 快速出手 |
| 引动 | 牵引使之响应 | 外部力量 |
| 运转 | 持续循环推动 | 功法、循环类 |
| 调动 | 从某处调用 | 资源型蛊虫 |
| 催炼 | 推动炼化过程 | 炼制场景 |
| 祭出 | 正式取出使用 | 法器、珍贵蛊虫 |

## 手法动作（身体如何发动法术）

| 候选词 | 动作 | 情绪/风格 |
|------|------|---------|
| 掐诀 | 手指结成特定形状 | 正式、仪式感 |
| 结印 | 双手结成印记 | 正式 |
| 点指 | 一指点出 | 简洁、高手感 |
| 一指 | 单指发动 | 极简，蛊真人特色 |
| 一挥袖 | 袖子扫过 | 从容、大宗师感 |
| 一挥手 | 随手发动 | 随意、实力碾压 |
| 按在 | 手掌贴上目标 | 控制、传递 |
| 贴上 | 轻轻附着 | 隐蔽、精细 |
| 扣上 | 扣住目标 | 锁定、强制 |
| 屈指一弹 | 指头弹出 | 轻巧、玩味 |
| 五指张开 | 展开手掌 | 释放范围效果 |

## 资源流转（能量/蛊虫的进出）

| 候选词 | 方向 | 适用 |
|------|------|------|
| 灌注 | 向外输出 | 给法器/他人充能 |
| 注入 | 向目标输入 | 控制、治疗 |
| 抽取 | 从目标抽出 | 吸收、掠夺 |
| 汲取 | 主动吸收 | 修炼、恢复 |
| 吸纳 | 被动接受 | 吸收外界能量 |
| 吞噬 | 强行消化 | 侵略性吸收 |
| 吞服 | 吃入体内 | 蛊虫/丹药 |
| 耗尽 | 资源清空 | 代价/失败 |

## 效果落地（法术作用于目标后的状态）

| 候选词 | 效果类型 | 语感 |
|------|---------|------|
| 绽放 | 光/花/爆炸扩散 | 视觉感强 |
| 蔓延 | 缓慢扩散 | 毒、腐蚀、寒冰 |
| 凝聚 | 向中心聚合 | 蓄力、成形前 |
| 凝炼 | 高密度压缩 | 炼制、强化 |
| 成形 | 从无形变有形 | 法阵、幻象 |
| 溃散 | 结构崩塌消散 | 防御破开 |
| 消散 | 自然消失 | 法术结束 |
| 弥漫 | 大范围扩散 | 气、雾、毒 |

## 蛊虫驱使（操控类动词）

| 候选词 | 操控方式 |
|------|---------|
| 驱使 | 命令使之行动 |
| 催使 | 催促加速行动 |
| 放出 | 从储存处释放 |
| 收回 | 召回至储存处 |
| 收入 | 纳入体内或器具 |
| 托起 | 以法力承托 |
| 操控 | 精细控制动作 |
| 遥控 | 远距离控制 |

---

## 蛊真人式施法特征

- **手法极简**：一指、一挥、屈指一弹，不写仪式，直接给结果。
- **资源显性化**：写仙元消耗、蛊虫折损，让代价可见。
- **效果不解释**：不写"他发出了一道火焰攻击"，直接写"火舌蔓延，笼罩半空"。
