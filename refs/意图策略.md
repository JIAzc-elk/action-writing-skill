# 意图策略 词库

> 本文件不按词索引，按**写作意图**索引。  
> 当作者知道想传达什么效果，但不知道用什么动作来实现时，从这里查。

---

## 一、隐瞒 / 掩盖某个动作

**核心原则**：隐瞒动作的人不会用大幅度、高声音、单步完成的动作。

| 策略 | 说明 | 示例 |
|------|------|------|
| 拆成多步+停顿 | 把一个动作拆成几下，每下之间停下来听动静 | 脚尖探过去，压住，停了一下，再慢慢蹭过去 |
| 借掩护动作 | 用另一个理由合理的动作（移椅子、咳嗽）制造声音或视觉遮盖 | 他起身拖了把椅子，借着声音把东西踢进桌底 |
| 注意力外移 | 写他把别人的注意力引向别处，或确认别人没看过来 | 他等对方低下头，才把手伸过去 |
| 留一个小破绽 | 人物以为藏好了，但有一处细节没控制住 | 茶水漫出了杯沿；衬衫领子歪了 |
| 身体余波 | 动作结束后的生理反应，说明紧张 | 才发现小腿一直绷着；手心出了汗 |
| 事后掩护 | 完成动作后，用另一个动作遮住或转移注意 | 他把椅子往前推了推，正好挡住那片位置 |

## 二、展示技巧 / 熟练度

**核心原则**：熟练的人动作是连贯的，步骤是简化的，不多余。

| 策略 | 说明 | 示例 |
|------|------|------|
| 动作链一气呵成 | 多个动作无停顿连接 | 他抽出笔摁了一下笔帽，在单子上划了两行 |
| 借物件体现熟练 | 物件在他手里的状态说明他与它的关系 | 刀在他手里翻了个面，笔杆在指间转了一圈 |
| 动作幅度极小 | 结果达到了，但外人看不出他做了什么 | 他手腕转了一下，锁开了 |
| 反向：生手写错误步骤 | 生手会多余、顺序错、需要重来 | 她把笔帽拔了又插上，又拔开，才开始写 |

## 三、表达轻蔑 / 嫌弃

| 策略 | 说明 | 示例 |
|------|------|------|
| 接触面极小 | 只用指尖，不用整只手 | 捏住一角递过去 |
| 动作收尾快 | 完成动作后立刻撤手，不多停留 | 对方还没接稳，他已经松了手 |
| 单方向不回应 | 给出动作后不看结果，转身或继续做别的 | 他把文件推过去，眼睛没离开屏幕 |
| 不调整姿态 | 不主动靠近，让对方来取 | 他把东西搁在桌边，没递过去 |
| 多余的等待 | 让对方等着，自己慢条斯理 | 他把东西放好，擦了擦手，才开口 |

---

## 四、强调紧张 / 恐惧

| 策略 | 说明 | 示例 |
|------|------|------|
| 感官异常 | 听觉/视觉放大，细节变得清晰 | 那点擦地声在他听来像炸开了 |
| 动作不准确 | 手抖、踩空、拿歪、没拿稳 | 她伸手去拿，差点没碰到 |
| 多余的重复 | 一个动作做了又做 | 他把手机锁上，放下，又拿起来看了一眼 |
| 注意力碎片化 | 同时注意太多地方，动作被打断 | 他刚把门带上，就听见身后有脚步声，手僵了一下 |
| 身体先于意识反应 | 身体动了，然后才反应过来 | 他往后退了一步，才意识到自己在退 |

---

## 五、表现克制 / 压抑情绪

**核心原则**：克制的人不是没有情绪，是情绪从边缘泄露。

| 策略 | 说明 | 示例 |
|------|------|------|
| 动作过于精准 | 控制过度，反而显出用力 | 他把杯子放下，位置摆得很正 |
| 多余的小动作 | 情绪出口转移到无关的手部动作 | 他一直在转那支笔，转了又转 |
| 停顿过长 | 该回应的时候没回应，空白本身说话 | 她问完，屋里静了很久，他才说"好" |
| 视线避开 | 情绪藏不住，所以不去看 | 他把东西放下，眼睛看着别处 |
| 身体收紧 | 肌肉、关节、呼吸的收紧 | 他的肩膀往上提了一下，又慢慢沉下去 |

---

## 六、表现失控 / 崩溃

| 策略 | 说明 | 示例 |
|------|------|------|
| 力度超出需要 | 拿东西的力气比必要的大得多 | 他把门带上，门框震了一下 |
| 动作顺序乱 | 步骤颠倒，或忘了中间一步 | 她穿上外套，才发现里头的扣子还没扣 |
| 破坏性动作 | 东西掉了、倒了、坏了，不收拾 | 杯子倒了，茶水流了一桌，他没动 |
| 语言与动作脱节 | 说的和做的不一致 | "我没事。"他说，手一直在抖 |

---

## 七、节奏控制

| 需求 | 策略 |
|------|------|
| 加快节奏 | 短句、单字动词、动作不解释 |
| 放慢节奏 | 拆成动作链、加感官细节、加停顿 |
| 高潮动作 | 前面慢铺，关键动作用短句单独成段 |
| 过场动作 | 保留笼统词，不展开 |
