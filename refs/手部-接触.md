# 手部·接触拿放 词库

覆盖：拿 / 放 / 递 / 给 / 交 / 还

| 攥 | 重 | 整只手握紧 | 中 | 紧张、愤怒、不愿放手 | |
| 抄 | 中 | 顺势一把抓起 | 快 | 情急、随意、果断 | |

## 放

**原词问题**：没有位置感、没有态度。

| 候选词 | 力度 | 方式 | 情绪倾向 | 慎用情形 |
|------|------|------|---------|---------|
| 搁 | 轻 | 随手搁置 | 随意、疲惫 | |
| 撂 | 中 | 随手丢下 | 轻蔑、不耐烦 | |
| 置 | 轻 | 刻意摆放 | 郑重、书面 | 现代口语偏生硬 |
| 摆 | 轻 | 有意排列 | 整齐、仪式感 | |
| 压 | 重 | 以重量固定 | 强势、威压 | |
| 丢 | 中偏重 | 随手抛落 | 嫌弃、不在乎 | |
| 推 | 中 | 推至某处停下 | 冷漠、强势 | 见手部-施力.md |
| 轻放 | 极轻 | 缓缓放下不出声 | 小心、不愿惊动 | 两字词，酌情用 |

## 递

**原词问题**：没有主动/被动之分，没有距离和态度。

| 候选词 | 主被动 | 接触方式 | 情绪倾向 | 慎用情形 |
|------|------|---------|---------|---------|
| 塞 | 主动 | 强行放入对方手中 | 热情、强势、不由分说 | |
| 送 | 主动 | 主动靠近给出 | 热情、讨好 | |
| 捧 | 主动 | 双手正式呈上 | 郑重、尊敬 | |
| 伸 | 被动 | 只伸出手，等对方来取 | 冷漠、不主动 | |
| 推 | 主动 | 推至对方面前 | 冷漠、强势 | |
| 甩 | 主动 | 用力甩向对方 | 愤怒、轻蔑 | 见手部-施力.md |
| 丢 | 主动 | 抛给对方 | 随意、轻蔑 | 见手部-施力.md |

## 给 / 交 / 还

这三个词本身不是问题，问题在于**怎么给**。

- **给**：先确认动作方式，再从"递"的候选词中选。
- **交**：强调移交责任，通常用于正式场合。可加方式词：郑重地交出、悄悄塞过去。
- **还**：强调归还，情绪重点在于归还时的态度：摔回去、轻轻放回去、欠身送还。
