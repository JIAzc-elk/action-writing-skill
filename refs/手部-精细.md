# 手部·精细动作 词库

覆盖：摸 / 碰 / 戳 / 捅 / 划 / 写 / 翻 / 撕

---

## 摸

**原词问题**：目的（探查/安抚/猥亵/习惯）与力度未分。

| 候选词 | 力度 | 方式 | 情绪/目的 | 慎用情形 |
|------|------|------|---------|---------|
| 抚 | 极轻 | 顺着表面缓慢移动 | 温柔、哀悼、安抚 | |
| 摩挲 | 轻 | 反复来回 | 思念、沉思、不安 | 偏书面 |
| 搓 | 中 | 双向摩擦 | 焦虑、取暖、犹豫 | |
| 捻 | 轻 | 指腹捻动 | 沉思、玩味 | |
| 抠 | 中 | 指尖抠挖 | 不安、挑剔、强迫 | |
| 探 | 轻 | 伸入试探 | 警惕、试探 | |
| 触 | 轻 | 一触即分 | 克制、试探 | 偏书面 |
| 拍 | 中 | 掌击表面 | 安抚、亲昵、催促 | |
| 搔 | 轻 | 轻挠 | 亲昵、戏谑 | |
| 抚平 | 轻 | 抚并展平 | 克制的在意 | 多指衣角、纸张 |

## 碰

**原词问题**：有意的还是无意的？礼貌的还是侵犯的？

| 候选词 | 意图 | 情绪倾向 |
|------|------|---------|
| 碰了碰 | 有意、轻 | 试探、提醒 |
| 碰到 | 无意 | 尴尬、巧合 |
| 挨 | 贴近 | 亲密或拥挤 |
| 蹭 | 擦过 | 亲昵、依赖、蹭便宜 |
| 顶 | 抵住 | 强势、抗议 |
| 撞 | 无意或有意 | 冲突、失控 |
| 磕 | 无意、有声 | 疼痛、鲁莽 |
| 接触 | 中性书面 | 偏书面 |

|------|------|---------|
| 戳 | 中 | 不耐、调笑、提醒 |
| 点 | 轻 | 指示、强调 |
| 捅 | 重 | 粗鲁、威胁、伤害 |
| 拨 | 轻 | 嫌弃、好奇 |
| 挠 | 轻 | 戏谑、试探 |

## 划

**原词问题**：工具、深度、目的未分。

| 候选词 | 工具 | 深度/力度 | 情绪倾向 |
|------|------|---------|---------|
| 划 | 锐器 | 浅 | 漫不经心或试探 |
| 割 | 锐器 | 深而断 | 伤害、决绝 |
| 刻 | 锐器 | 有痕迹 | 郑重、执念 |
| 抓 | 指甲 | 表皮 | 愤怒、失控 |
| 划拉 | 任意 | 草率 | 随意、敷衍 |
| 画 | 笔 | 表面 | 绘制 |

---

## 写

多为过程描写，重点不在换词，而在**手的状态**：字歪了（手抖）、笔画重得戳破纸（用力）、写到一半停笔（迟疑）。动词本身少换。
