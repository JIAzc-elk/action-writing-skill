# 战术位移 词库

覆盖：追杀 / 撤退 / 逃亡 / 突围 / 追踪

> 和"移动-步行.md"的区别：  
> 步行写**怎么走**（步态、速度、姿态）；  
> 战术位移写**为什么移动**（战略目的、空间控制）。

---

## 追击

| 候选词 | 特征 | 情绪倾向 |
|------|------|---------|
| 追杀 | 追上就要杀 | 危险、决绝 |
| 追击 | 追上并攻击 | 中性战术 |
| 追赶 | 单纯缩短距离 | 中性 |
| 紧追 | 保持压力不放松 | 逼迫感 |
| 咬住 | 锁定目标不脱钩 | 执着、凶狠 |
| 拦截 | 预判路线提前卡位 | 聪明、主动 |
| 围堵 | 多方向封锁 | 包围感 |
| 追踪 | 循迹跟随 | 耐心、专业 |

---

## 撤退（主动）

| 候选词 | 意图 | 情绪倾向 |
|------|------|---------|
| 撤退 | 有序离开战场 | 战术性，不狼狈 |
| 撤离 | 从区域撤出 | 中性 |
| 后撤 | 向后移动拉开距离 | 临时调整 |
| 转进 | 以撤退掩护战术转变 | 高手感（实为撤退） |
| 脱身 | 从纠缠中摆脱 | 灵活 |
| 抽身 | 从局面中退出 | 主动、不被动 |
| 收缩 | 缩小战线，集中防守 | 战略性 |

---

## 逃亡（被动）

| 候选词 | 程度 | 情绪倾向 |
|------|------|---------|
| 逃窜 | 重 | 狼狈、失控方向 |
| 仓皇逃窜 | 极重 | 完全失序 |
| 夺路而逃 | 重 | 强行冲开 |
| 落荒而逃 | 极重 | 彻底溃败 |
| 仓皇出逃 | 重 | 时间紧迫 |
| 狼狈逃脱 | 重 | 有损颜面 |
| 遁走 | 中 | 玄幻常用，快速消失 |
| 隐遁 | 中 | 隐身后撤 |
| 潜逃 | 中 | 秘密离开 |

---

## 突围

| 候选词 | 方式 | 情绪倾向 |
|------|------|---------|
| 突围 | 强行冲破包围 | 决死感 |
| 破围 | 打破包围圈 | 主动出击 |
| 冲出 | 直线强突 | 蛮力或速度 |
| 寻隙 | 找到破绽后出逃 | 冷静 |
| 借道 | 利用对方阵型漏洞 | 聪明 |
| 杀出重围 | 以攻代守冲出 | 悲壮 |

---

## 摆脱 / 甩开

| 候选词 | 方式 |
|------|------|
| 摆脱 | 通用，甩掉追击 |
| 甩开 | 拉开足够距离 |
| 脱钩 | 切断追击者的锁定 |
| 断后 | 安排人留下阻击，主力撤退 |
| 殿后 | 同上，更正式 |
| 迷惑 | 制造假目标干扰追击 |
| 绕行 | 走迂回路线避开追击 |

---

## 空间控制词

这类词描述位置和控制权，不是单纯的移动：

| 词 | 含义 |
|---|------|
| 卡位 | 占据有利位置 |
| 封死 | 堵住所有退路 |
| 压缩 | 缩小对方的活动空间 |
| 牵制 | 限制对方行动自由 |
| 包抄 | 从侧翼或后方绕过 |
| 迂回 | 绕过正面从侧后攻击 |
| 拉开距离 | 主动制造空间 |
| 贴身 | 消除距离，限制对方出招 |

---

## 写法特征

**战术位移要写"为什么移"，不只是"往哪移"**：

> ❌ 他往后退了十步。  
> ✅ 他后退十步，把对方的攻击引离了那扇门——门后还有人。

**撤退和逃亡的区别**在于是否还有主动意志：
> 撤退：他判断此战无益，收手后退。  
> 逃亡：他已顾不上方向，只想离那东西远一点。
