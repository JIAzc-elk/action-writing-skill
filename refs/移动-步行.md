# 移动·步行与足部 词库

覆盖：走 / 迈 / 跑 / 冲 / 奔 / 踢 / 蹬 / 踩 / 勾 / 拖步

---

## 走

**原词问题**：速度、姿态、目的、情绪全部缺失。

| 候选词 | 速度 | 姿态/特征 | 情绪倾向 | 慎用情形 |
|------|------|---------|---------|---------|
| 迈 | 中 | 步幅大、有意识 | 从容、有目的 | |
| 踱 | 慢 | 来回缓行 | 沉思、焦虑、权威 | |
| 踽踽 | 慢 | 孤独缓行 | 落寞、孤独 | 偏书面 |
| 蹒跚 | 慢 | 步态不稳 | 衰老、受伤、醉 | |
| 踉跄 | 慢 | 踩空将跌 | 惊吓、受击、醉 | |
| 疾步 | 快 | 步幅大步频高 | 急切、紧张 | |
| 大步 | 快 | 步幅大 | 自信、急切 | |
| 碎步 | 中 | 步幅小步频高 | 拘谨、急切、小心 | |
| 趋 | 快 | 小步快走向前 | 恭敬、奔赴 | 偏书面 |
| 溜 | 中 | 悄悄离开 | 鬼祟、逃跑 | |
| 闪 | 快 | 迅速侧移 | 躲避、机警 | 实际语料中"闪身"低频，多用"一闪""挪移""腾挪" |
| 挪移 | 快 | 瞬间位移至别处 | 玄幻、法术 | 高频替代"闪身" |
| 退 | 中 | 向后移动 | 示弱、警惕、让步 | |
| 挪 | 慢 | 一点点移动 | 不情愿、笨重、小心 | |
| 蹑手蹑脚 | 慢 | 刻意无声 | 偷偷摸摸、紧张 | |

## 跑 / 冲 / 奔

| 候选词 | 速度 | 特征 | 情绪倾向 |
|------|------|------|---------|
| 奔 | 极快 | 全力 | 急切、逃命、奔赴 |
| 冲 | 极快 | 朝目标直线 | 愤怒、急切、鲁莽 |
| 窜 | 快 | 方向不定 | 鬼祟、仓皇 |
| 蹿 | 快 | 向上或快速突进 | 惊吓、敏捷 |
| 夺路 | 快 | 强行通过 | 狼狈、仓皇 |
| 落荒 | 极快 | 仓皇逃窜 | 狼狈 |
| 疾奔 | 极快 | 全力冲刺 | 急迫 |

> 注："掠出"在实际语料中多作"掠过""掠去"，单用"掠出"慎用。

## 足部精细动作

### 踢

**原词问题**：踢是大幅度、有声音的动作，不适合"悄悄"语境。

| 候选词 | 幅度 | 声音 | 适用场景 | 情绪倾向 |
|------|------|------|---------|---------|
| 拨 | 小 | 轻微 | 悄悄移动小物件 | 隐蔽、紧张 |
| 蹭 | 极小 | 几乎无声 | 贴地面缓慢移动 | 隐瞒、小心 |
| 勾 | 小 | 轻微 | 脚尖勾住并移动 | 隐蔽、习惯 |
| 拖 | 中 | 擦地声 | 物件较重 | |
| 踢 | 大 | 有声 | 明显动作 | 情急、愤怒 |
| 踹 | 大 | 强力冲击 | 破坏性 | 愤怒、暴力 |

---

### 踩 / 蹬 / 勾

| 候选词 | 方向 | 力度 | 情绪倾向 |
|------|------|------|---------|
| 踩 | 向下 | 中 | 压制、稳住、蔑视 |
| 踏 | 向下 | 中 | 郑重、确认 |
| 蹬 | 向外/向后 | 重 | 借力、反击、逃脱 |
| 勾 | 向内 | 轻 | 细腻、隐蔽、绊倒 |
| 绊 | 向侧 | 中 | 意外或故意使绊 |
| 跺 | 向下、原地 | 重 | 愤怒、强调 |
