# 手部·抓握施力 词库

覆盖：抓 / 抢 / 推 / 拉 / 拽 / 拖 / 甩 / 丢 / 扔 / 砸 / 打

---

## 抓

**原词问题**：力度、意图、成败皆含糊。

| 候选词 | 力度 | 接触方式 | 情绪倾向 | 慎用情形 |
|------|------|---------|---------|---------|
| 攥 | 重 | 整手握紧不松 | 紧张、愤怒、执念 | |
| 揪 | 重 | 抓住并拉扯 | 愤怒、急切 | 多用于衣领、头发、耳朵 |
| 拽 | 中偏重 | 用力拖拉 | 强势、急切 | |
| 拎 | 中 | 提起 | 随意、轻蔑 | |
| 揪住 | 重 | 定格于一点 | 对峙、制止 | |
| 攥紧 | 重 | 持续状态 | 克制的怒 | |
| 捏 | 轻 | 指尖掐住 | 轻视、拿捏 | |
| 扣 | 重 | 手指扣住 | 强势、控制 | 多用于手腕、扳机 |
| 搂 | 中 | 环抱 | 亲密、保护 | |
| 抄 | 快 | 顺手抓起 | 情急 | |

## 推

**原词问题**：力度、对象、情绪未分。

| 候选词 | 力度 | 方式 | 情绪倾向 | 慎用情形 |
|------|------|------|---------|---------|
| 搡 | 中偏重 | 粗暴推开 | 粗鲁、愤怒 | 北方口语 |
| 顶 | 重 | 用力抵住 | 抵抗、强势 | |
| 拱 | 中 | 蛮力挤开 | 市井、蛮横 | |
| 搡开 | 重 | 猛力推开 | 愤怒、粗暴 | |
| 抵 | 中 | 持续施力 | 阻挡、克制 | |
| 拨 | 轻 | 快速分开 | 不耐、嫌恶 | |
| 攘 | 重 | 用力猛推 | 愤怒、绝望 | |
| 挤 | 中 | 靠身体挤过 | 匆忙、无礼 | |

## 拉 / 拽 / 拖

**原词问题**：三者力度与态度不同，"拉"最中性。

| 候选词 | 力度 | 方式 | 情绪倾向 |
|------|------|------|---------|
| 拽 | 中偏重 | 粗暴拖动 | 急切、强势 |
| 拖 | 重 | 沿地面拖行 | 虐待、粗暴、沉重 |
| 扯 | 中 | 拉扯变形 | 急切、失控 |
| 搀 | 轻 | 扶住牵引 | 关怀、照料 |
| 挽 | 轻 | 手臂相挽 | 亲密、陪伴 |
| 牵 | 轻 | 手指相扣 | 亲密、引导 |
| 揪 | 重 | 猛力拉扯 | 愤怒 |

---

## 甩 / 丢 / 扔 / 砸

**原词问题**：四者攻击性与情绪等级完全不同。

| 候选词 | 力度 | 轨迹 | 情绪倾向 | 慎用情形 |
|------|------|------|---------|---------|
| 甩 | 中 | 借腕力横抛 | 愤怒、决裂、甩脱 | |
| 丢 | 中 | 随手一抛 | 嫌弃、不在乎 | |
| 掷 | 重 | 有目标的抛出 | 决绝、正式 | 偏书面 |
| 扔 | 中 | 随意抛出 | 不耐、随便 | |
| 摔 | 重 | 落地有声 | 暴怒、崩溃 | |
| 砸 | 重 | 用力击落 | 狂怒、毁灭欲 | |
| 撂 | 中 | 随手放下 | 不在乎 | 多指放下，非抛出 |
| 抛 | 中 | 高轨迹投出 | 漫不经心或有意 | |
| 摔 | 重 | 用力摔门/摔杯 | 愤怒 | 搭配对象：门、杯、碗 |

## 打

**原词问题**：是打人、打门还是打手势？先确认对象，再从下表选。

| 对象 | 候选词 | 说明 |
|------|------|------|
| 人 | 扇 / 捅 / 揍 / 拳 / 掌掴 / 挥 | 按武器与部位细分 |
| 门/物 | 拍 / 捶 / 敲 / 踹 / 撞 | 按力度与意图分 |
| 手势 | 比 / 划 / 摆 / 挥手 | 多为示意 |
| 电话 | 拨 / 按 / 挂 | |
| 信号 | 打了个手势 | 见意图策略.md |
