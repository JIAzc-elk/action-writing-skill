# 移动·姿态 词库

覆盖：站 / 坐 / 躺 / 趴 / 蹲 / 靠 / 转 / 回

---

## 站

**原词问题**：站是结果，缺少过渡动作和姿态信息。

| 候选词 | 过渡/姿态 | 情绪倾向 | 慎用情形 |
|------|---------|---------|---------|
| 立 | 笔直 | 正式、威严、克制 | 过于书面 |
| 伫立 | 静止较久 | 沉思、等待、落寞 | 偏书面 |
| 屹立 | 纹丝不动 | 意志、对抗 | 偏书面/宏大 |
| 站定 | 停步站住 | 对峙、决意 | |
| 顿住 | 突然停步 | 惊讶、警觉 | |
| 僵住 | 完全静止 | 惊恐、尴尬 | |
| 撑起 | 用力支起身体 | 虚弱中的坚持 | |
| 起身 | 从坐/躺变为站 | 中性过渡 | |
| 直起 | 从弯腰变直 | 中性或迎接 | |

---

## 坐

**原词问题**：缺少姿势（坐法）与态度。

| 候选词 | 坐法/特征 | 情绪倾向 |
|------|---------|---------|
| 落座 | 正式入座 | 礼貌、被动接受 |
| 瘫坐 | 软倒 | 崩溃、疲惫、放弃 |
| 窝 | 缩进去 | 懒散、依赖、安全感 |
| 端坐 | 腰背挺直 | 正式、克制、防御 |
| 箕坐 | 两腿伸直 | 随意、无礼（部分场合） |
| 侧坐 | 身体侧向一方 | 不正式、疲惫 |
| 跌坐 | 腿软跌倒坐下 | 受击、恐惧 |
| 蜷 | 缩成一团 | 恐惧、悲伤、寒冷 |

---

## 躺 / 趴

| 候选词 | 姿势 | 情绪倾向 |
|------|------|---------|
| 仰躺 | 面朝上 | 放松、绝望 |
| 侧躺 | 侧身 | 随意、疲惫 |
| 蜷缩 | 缩成一团 | 恐惧、悲伤、保护自己 |
| 瘫倒 | 完全放弃支撑 | 崩溃、受伤 |
| 趴伏 | 面朝下伏地 | 顺从、隐藏、受伤 |
| 匍匐 | 贴地爬行 | 隐蔽、逃跑、极度虚弱 |

---

## 蹲

| 候选词 | 特征 | 情绪倾向 |
|------|------|---------|
| 蹲下 | 两腿弯曲 | 中性、平视弱小者 |
| 蜷缩 | 缩成最小 | 恐惧、防御 |
| 俯身 | 上身前倾 | 检视、关怀 |
| 弓身 | 腰背弓起 | 防御、受伤 |
| 半蹲 | 准备状态 | 警戒、蓄力 |

---

## 靠

| 候选词 | 力度/方式 | 情绪倾向 |
|------|---------|---------|
| 倚 | 轻 | 随意、疲惫、依赖 |
| 伏 | 压下去 | 疲惫、藏匿 |
| 贴 | 紧密 | 亲密、恐惧（躲避） |
| 蜷靠 | 缩着靠 | 安全感、依赖 |
| 抵 | 顶住 | 阻力、克制 |
| 偎 | 紧贴 | 亲昵、撒娇 |

---

## 转 / 回

| 候选词 | 幅度 | 速度 | 情绪倾向 |
|------|------|------|---------|
| 转身 | 180° | 中 | 中性 |
| 猛地转过来 | 180° | 快 | 惊讶、愤怒 |
| 侧过脸 | 小幅 | 慢 | 克制的关注 |
| 回头 | 中 | 中 | 不舍、确认、警觉 |
| 扭头 | 中 | 快 | 不屑、逃避 |
| 转过身去 | 180° | 慢 | 拒绝、伤心 |
| 背过身 | 180° | 中 | 拒绝、隐藏表情 |
