# 礼仪·社交动作 词库

覆盖：行礼 / 拜见 / 馈赠交接 / 告辞 / 违礼拒绝

> 适用于古风、武侠、玄幻、历史等有等级体系的场景。  
> 一次拱手就能交代双方实力位阶，省三段心理描写。

---

## 核心原则

礼仪动作是**等级语言**。谁先行礼、行什么礼、对方如何回应，直接显示双方地位。  
不用写"他知道对方比自己强很多"——写他行什么礼就够了。

---

## 行礼（由重到轻）

| 候选词 | 程度 | 适用场景 |
|------|------|---------|
| 跪拜 | 极重 | 君臣、神明、极大恩情 |
| 大礼参见 | 重 | 正式场合见尊者 |
| 拜见 | 重 | 下见上，正式 |
| 参见 | 重 | 同上，更书面 |
| 躬身行礼 | 中 | 通用敬礼 |
| 躬身 | 中 | 躬身不到90° |
| 鞠躬 | 中 | 通用 |
| 拱手 | 中轻 | 武林通用礼节，平辈或稍下 |
| 抱拳 | 中轻 | 武林礼节 |
| 颔首 | 轻 | 点头示意，平辈或稍上 |
| 微微欠身 | 极轻 | 有身份者对地位略低者 |
| 以礼相待 | — | 叙述层面，不直接描写动作 |

---

## 回礼（上对下的回应）

| 候选词 | 传达信息 |
|------|---------|
| 颔首 | 认可，不失身份 |
| 抬手虚扶 | "不必多礼"，显示亲近 |
| 点头受礼 | 接受，默认地位差距 |
| 受而不答 | 冷漠或地位极高 |
| 视而不见 | 蔑视或敌意 |

---

## 献上 / 交接

| 候选词 | 方式 | 情绪倾向 |
|------|------|---------|
| 献上 | 双手呈上，主动给予 | 恭敬 |
| 奉上 | 恭敬递上 | 正式 |
| 呈上 | 正式提交 | 官方场合 |
| 敬上 | 表达敬意地给出 | 礼貌 |
| 递上 | 普通传递 | 中性 |
| 接过 | 从对方手中取到 | 中性 |
| 收下 | 接受并保留 | 接受馈赠 |
| 双手接过 | 表示重视 | 礼貌、郑重 |

---

## 推辞 / 拒绝

| 候选词 | 程度 | 场景 |
|------|------|------|
| 推辞 | 轻 | 客套性拒绝 |
| 婉拒 | 轻中 | 有礼貌地拒绝 |
| 谢绝 | 中 | 较明确的拒绝 |
| 拒而不受 | 中 | 坚持不接受 |

---

## 告辞 / 离场

| 候选词 | 场景 |
|------|------|
| 告辞 | 主动离开，向对方打招呼 |
| 拱手告辞 | 武林场景 |
| 起身离去 | 中性 |
| 拂袖而去 | 愤怒或不屑地离开 |
| 转身离去 | 中性，动作感 |
| 飘然离去 | 高手感，潇洒 |

---

## 赔礼 / 道歉

| 候选词 | 程度 |
|------|------|
| 赔礼 | 轻，口头道歉 |
| 赔罪 | 重，承认过失 |
| 负荆请罪 | 极重，书面/古风 |
| 俯首认罪 | 重 |

---

## 礼仪作为信息工具

**以礼交代位阶**：
> 那人一进门便拱手，态度恭谨。对方只颔首，连起身也没有。

**以礼交代关系变化**：
> 上次见面他还会抱拳行礼。今天直接开口说话，连点头都省了。

**以违礼制造张力**：
> 他本该行礼，却只是站着，眼神平视。堂上安静了一瞬。
