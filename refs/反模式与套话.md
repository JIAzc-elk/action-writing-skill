# 反模式与套话 清单

> 本文件记录写作中常见的低质量动作描写模式。  
> 改写时若出现以下模式，优先处理。

---

## 一、情绪直说

直接用情绪词替代动作，读者被告知感受，而非自己感受到。

| 反模式示例 | 问题 | 修改方向 |
|---------|------|---------|
| 他很紧张地拿起了杯子 | "很紧张"是作者的解释 | 写手的动作：杯子碰了桌边，发出一声响 |
| 她开心地走过去 | "开心"是标注 | 写步伐：她几乎是跑过去的 |
| 他害怕地看着门 | "害怕"是注解 | 写视线：他的眼睛一直没离开门缝 |
| 她愤怒地摔门 | "愤怒"和"摔"重复 | 保留"摔"，删"愤怒地" |

---

## 二、网文套话动词

这类词已被用烂，读者的眼睛会自动跳过，不产生画面。

| 禁用词 | 问题 |
|------|------|
| 眸光一闪 | 滥用；"眸"本身也偏套 |
| 嘴角勾起 | 滥用；没有具体幅度和方向 |
| 薄唇微启 | 偏套；"薄唇"是体貌词，不是动作 |
| 凤眸微眯 | 滥用；"凤眸"是固定标签 |
| 冷眸扫过 | 双重形容（冷+扫），叠床架屋 |
| 淡淡开口 | "淡淡"无内容；见言语.md |
| 修长手指 | 是体貌词，出现在动作描写里常为硬塞 |
| 漫不经心地 | 被滥用成空洞的腔调词 |
| 云淡风轻地 | 同上 |

---

## 三、副词/形容词堆砌

用多个修饰词堆出感觉，代替具体动作。

| 反模式示例 | 问题 | 修改方向 |
|---------|------|---------|
| 轻柔地、缓缓地、小心翼翼地抚摸 | 三个副词做的事，一个动词能做 | "摩挲"或"轻抚"，删副词 |
| 冷静而又克制地转过身 | "冷静""克制"都是情绪注释 | 写动作本身，把停顿写出来 |
| 不紧不慢地、从容地、淡定地走过去 | 重复注释 | 用步态词：踱、缓步 |

---

## 四、对话标签滥用

把说话方式和情绪同时塞进标签。详见 [言语.md](言语.md)。

| 反模式 | 修改方向 |
|------|---------|
| 冷声道/冷笑道/淡淡道 | 删标签，用动作引出对白 |
| 低吼道/怒吼道 | 拆成：他低着声音说 / 他几乎是吼出来的 |
| 轻笑道 | 拆成：他笑了一下，然后说 |

---

## 五、改变原文信息

改写时不得增加、删除、改变：
- 原文已有的情节信息
- 人物已有的性格设定（若作者没提供，则只能问，不能自行设定）
- 场景中的人物关系
- 时间线和逻辑顺序

---

## 六、过度精修

并非所有动作都需要精确描写。以下情形保留笼统词：

| 情形 | 建议 |
|------|------|
| 过场动作（走到门口、拿起手机） | 保留，不展开 |
| 高密度对话中的穿插动作 | 保留或删除，不展开 |
| 一段里精修动作已超过3处 | 剩余保留，避免密度过高 |
| 叙述层面的概括（他收拾了东西） | 不属于场景动作，不改 |

---

## 七、常见多余句式

| 句式 | 问题 |
|------|------|
| 只见他…… | "只见"是视角提示语，现代小说基本不用 |
| 但见她…… | 同上 |
| 他做了个动作 | 双重笼统，直接写动作 |
| 她不由自主地 | 多余说明，动作本身能表达 |
| 下意识地 | 滥用；偶尔可用，不可成习惯 |
