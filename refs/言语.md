# 言语 词库

覆盖：说 / 讲 / 告诉 / 回答 / 问

---

## 核心原则：慎换对话标签

"说"是最中性、最透明的对话标签，读者不会注意它，只会看对话内容本身。
把"说"换成"低吼道""轻笑道""冷声道"是网文最常见的毛病之一——见反模式文件。

**优先于换词的两个策略**：

1. **保留"说"，把情绪放进对话内容和动作里。**
2. **删掉标签，改用一个动作引出对白。**

例：  
❌ "你走！"她冷声道。  
✅ 她把杯子推到他面前。"你走。"

| 耳语 | 极低 | 贴耳 | 秘密 | |

## 对话标签反模式（禁用或慎用列表）

这些词自带情绪标签，会替读者做判断，削弱文字的张力：

| 禁用/慎用 | 问题所在 | 替代方向 |
|---------|---------|---------|
| 冷声道 | 告诉读者她冷漠，读者无需感受 | 用动作+对话内容体现 |
| 低吼道 | 拟声词+叙述，双重说明 | 保留"说"，动作另写 |
| 轻笑道 | 笑的同时说话，动作和对话互抢 | 拆成两句 |
| 沉声道 | 偏套话 | 低声 / 直接省掉标签 |
| 淡淡道 | 滥用 | 用动作替代 |
| 咬牙道 | 生理描写代替情绪 | 偶尔可用，不可滥用 |
| 喟叹道 | 双重叙述 | 叹了口气，然后说 |
