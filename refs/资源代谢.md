# 资源代谢 词库

覆盖：消耗 / 维持 / 补充 / 修复恢复

> 适用于任何"力量有代价"的系统：修真灵力、武侠内力、现代体力、魔法魔力、科幻能量。  
> 这类写法的核心是**把状态写成流量**，不是写肌肉，是写账目。

---

## 核心原则

资源代谢的句子形态：  
> 「他咬牙撑住，真气以每息三成的速度流失。」  
> 「战斗仅持续了十息，他的灵力已不足两成。」

关键：动作是**数字在变动**，不是身体在用力。

---

## 支出（消耗/流失）

| 候选词 | 程度 | 语感 |
|------|------|------|
| 消耗 | 中性 | 通用，最常用 |
| 耗费 | 中 | 稍强调量 |
| 动用 | 中 | 主动调取 |
| 透支 | 重 | 超出上限 |
| 耗尽 | 极重 | 彻底清空 |
| 枯竭 | 极重 | 彻底无法使用 |
| 流失 | 中 | 被动、持续减少 |
| 散逸 | 轻偏中 | 自然散失，常用于法术结束后 |
| 燃烧 | 重 | 急速消耗，代价感强 |
| 榨干 | 极重 | 被外力彻底抽空 |

---

## 维持（持续占用而不消失）

| 候选词 | 用法 |
|------|------|
| 维持 | 保持某状态运转 |
| 支撑 | 以力量撑住不崩 |
| 镇压 | 强行压制不稳定的力量 |
| 牵制 | 一部分力量被锁住无法使用 |
| 占用 | 资源被某效果持续占据 |
| 压住 | 临时强制稳定 |

---

## 补入（补充/储存）

| 候选词 | 方式 | 语感 |
|------|------|------|
| 补充 | 主动添加 | 中性 |
| 恢复 | 自然回升 | 中性 |
| 积蓄 | 缓慢积累 | 时间感强 |
| 储备 | 提前储存 | 有规划感 |
| 节省 | 减少消耗 | 被动控制 |
| 填补 | 补足缺口 | 修复感 |
| 汲取 | 从外部主动吸收 | 主动、玄幻常用 |
| 吸纳 | 被动或主动接收 | 玄幻常用 |
| 吞噬 | 强行消化吸收 | 侵略性 |
| 炼化 | 转化为自身可用 | 见炼化工艺.md |

---

## 修复（疗伤/复原）

| 候选词 | 程度 | 适用 |
|------|------|------|
| 疗伤 | 中 | 主动处理伤口 |
| 休养 | 轻 | 被动恢复，需要时间 |
| 治愈 | 重 | 完全恢复 |
| 复原 | 重 | 恢复至原状 |
| 稳住 | 轻 | 防止继续恶化 |
| 续命 | 极重 | 临界状态下勉强维持 |
| 强撑 | 中 | 意志力对抗伤势 |

## 状态标记词（配合资源动词使用）

这类词表示资源当前水位，配合动词交代战斗底牌：

| 词 | 含义 |
|---|------|
| 不足两成 | 量化剩余 |
| 强弩之末 | 接近耗尽 |
| 气息紊乱 | 内部失控 |
| 经脉受损 | 通道受阻 |
| 神魂动荡 | 精神资源受损 |
| 底牌尽出 | 储备用完 |

## 写法示例

**账目式（最有张力）**：
> 一道杀招轰出，他感到识海中的神念消耗了小半。对方还有三招。他未必撑得住。

**对比式（强调代价）**：
> 敌人面色如常，他已透支过半。同样是出招，消耗相差三倍。

**临界式（制造悬念）**：
> 真气仅剩最后一缕。够发一招，仅此而已。
