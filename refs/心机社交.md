# 心机·社交战斗 词库

覆盖：试探 / 拖延 / 欺骗伪装 / 要挟逼迫 / 离间拆解 / 借势布局

> 适用于权谋、悬疑、商战、玄幻等任何人物之间存在利益博弈的场景。  
> 这类动词的特征：**动作极小，后果极大**，和战斗动词正好互补。

---

## 核心原则

社交战斗不是正面冲突，是**信息差的争夺**。  
一次"试探"可以是对话里的一个问题，一次"布局"可以是数月前的一个决定。

---

## 探（获取信息）

| 候选词 | 方式 | 情绪倾向 |
|------|------|---------|
| 试探 | 小步验证，观察反应 | 谨慎、算计 |
| 打探 | 主动向外打听 | 中性 |
| 摸底 | 彻底了解对方实力 | 谨慎 |
| 套话 | 通过闲聊提取信息 | 隐蔽 |
| 刺探 | 秘密获取 | 危险、违规感 |
| 窥探 | 偷偷察看 | 隐蔽、鬼祟 |
| 盘问 | 有目的的反复追问 | 威压感 |

---

## 拖（时间博弈）

| 候选词 | 方式 | 情绪倾向 |
|------|------|---------|
| 拖延 | 推迟、不正面回应 | 被动或战术 |
| 观望 | 不动，等局势明朗 | 冷静 |
| 坐视 | 有意不介入 | 冷漠或算计 |
| 按捺 | 强压冲动等待时机 | 克制 |
| 隐忍 | 长期压抑，等待时机 | 蓄力感 |
| 蛰伏 | 彻底隐藏不出手 | 深谋远虑 |
| 敷衍 | 表面应付，不实质回应 | 轻蔑或谨慎 |

---

## 骗（信息欺诈）

| 候选词 | 方式 | 情绪倾向 |
|------|------|---------|
| 欺骗 | 主动制造假信息 | 中性 |
| 蒙骗 | 利用对方疏忽 | 轻巧 |
| 欺瞒 | 长期隐瞒 | 有持续感 |
| 隐瞒 | 刻意不说 | 中性偏被动 |
| 伪装 | 改变外在形象 | 主动 |
| 示弱 | 故意表现弱小 | 计谋 |
| 冒充 | 以假身份行事 | 风险感 |
| 诈败 | 假装落败 | 高手计谋 |
| 误导 | 让对方得出错误结论 | 精准操控 |

---

## 逼（施压）

| 候选词 | 程度 | 情绪倾向 |
|------|------|---------|
| 威胁 | 中 | 通用施压 |
| 要挟 | 重 | 以把柄施压 |
| 勒索 | 重 | 以把柄索取利益 |
| 敲诈 | 重 | 同上，更口语 |
| 逼迫 | 重 | 直接强制 |
| 施压 | 中 | 通用 |
| 拿捏 | 中 | 掌握对方弱点 |

---

## 拆（瓦解对方阵营）

| 候选词 | 方式 | 情绪倾向 |
|------|------|---------|
| 离间 | 在两人之间制造猜忌 | 阴险 |
| 挑拨 | 激化对方矛盾 | 主动煽动 |
| 栽赃 | 嫁祸他人 | 恶意强 |
| 策反 | 收买对方人员 | 战略 |
| 出卖 | 将对方信息卖给敌人 | 背叛感 |
| 倒戈 | 临阵转投对方 | 突然背叛 |

---

## 借（借力打力）

| 候选词 | 方式 | 情绪倾向 |
|------|------|---------|
| 借势 | 借用他人的威势 | 聪明 |
| 顺势 | 乘势而为 | 灵活 |
| 借刀 | 利用第三方去打击目标 | 阴险或聪明 |
| 引诱 | 设置诱饵吸引对方 | 主动设局 |
| 利用 | 把他人当工具 | 冷酷 |

---

## 设（主动布局）

| 候选词 | 时间维度 | 情绪倾向 |
|------|---------|---------|
| 布局 | 长期 | 深谋远虑 |
| 布置 | 中期 | 具体安排 |
| 设伏 | 短期 | 针对某次行动 |
| 埋伏 | 短期 | 等待目标进入 |
| 落子 | 长期 | 棋局感，高手 |
| 铺垫 | 长期 | 为未来动作做准备 |
| 下套 | 中短期 | 设陷阱 |

## 写法特征

**动作小、信息量大**：一句"他沉默了一瞬"可以是选择，不是无话可说。

**对话即战场**：
> ❌ 他想试探对方知不知道这件事。  
> ✅ 他提到了北城的货，眼角余光扫过去。对方的茶杯停了一下。

**结果延迟**：布局类动词往往在数段甚至数章后才见效，写的时候只写动作，不写结果。
