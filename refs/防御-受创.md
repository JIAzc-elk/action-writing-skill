# 防御·化解·受创·死亡 词库

覆盖：硬接 / 化劲 / 闪避 / 受创程度 / 蛊虫专属崩溃

---

## 防御 / 化解

### 硬接

| 候选词 | 特征 | 情绪倾向 |
|------|------|---------|
| 格挡 | 以武器或臂膀挡住 | 稳重、主动防御 |
| 架住 | 举起撑住来势 | 临时、被动 |
| 硬抗 | 不化解直接承受 | 蛮力、展示强度 |
| 顶住 | 以力抵力 | 坚持、克制 |
| 承受 | 被动接下 | 无力化解 |

### 化劲 / 卸力

| 候选词 | 特征 | 情绪倾向 |
|------|------|---------|
| 卸开 | 借力化解方向 | 技巧、从容 |
| 化去 | 完全消弭 | 高手感 |
| 拨开 | 偏转方向 | 轻巧 |
| 荡开 | 以气劲推散 | 玄幻常用 |
| 弹开 | 反弹力道 | 被动或主动皆可 |
| 消弭 | 彻底消除 | 绝对防御感 |

### 闪避

| 候选词 | 幅度 | 特征 |
|------|------|------|
| 侧身 | 小 | 最小移动，高手感 |
| 偏头 | 极小 | 仅头部移动 |
| 后仰 | 中 | 身体后倒 |
| 闪避 | 中 | 通用 |
| 翻滚 | 大 | 狼狈或战术性 |
| 后撤 | 中 | 主动拉开距离 |
| 倒飞 | 大 | 被动弹出 |
| 拉开距离 | 大 | 战略后退 |

## 受创程度

### 轻微

| 候选词 | 表现 | 叙事功能 |
|------|------|---------|
| 踉跄 | 步伐不稳 | 受击信号 |
| 闷哼 | 压抑的痛声 | 克制的伤 |
| 皱眉 | 面部收紧 | 轻微不适 |
| 气血翻涌 | 内部震动 | 玄幻特有，表示内伤 |
| 汗毛倒竖 | 本能警觉 | 危险感知 |
| 色变 | 脸色变化 | 心理受创 |

### 中度

| 候选词 | 表现 |
|------|------|
| 喷血 | 吐出血液，受重伤信号 |
| 吐血 | 同上，稍轻 |
| 跪倒 | 腿部力量失控 |
| 栽倒 | 整体前倾倒下 |
| 瘫软 | 全身力量消失 |
| 抽搐 | 失控的肌肉反应 |
| 脱力 | 力量耗尽 |

### 重度 / 死亡

| 候选词 | 表现 | 语感 |
|------|------|------|
| 崩解 | 结构性瓦解 | 玄幻 |
| 湮灭 | 完全消失 | 玄幻绝杀 |
| 灰飞烟灭 | 彻底毁灭 | 玄幻 |
| 陨落 | 高手死亡的书面表达 | 庄重 |
| 毙命 | 直接死亡 | 中性 |
| 气绝 | 断气 | 偏书面 |

### 蛊虫 / 秘法专属崩溃

| 词 | 含义 |
|---|------|
| 反噬 | 蛊虫或法术反过来伤害使用者 |
| 爆蛊 | 蛊虫自爆 |
| 蛊虫暴毙 | 蛊虫死亡 |
| 窍壁龟裂 | 经脉受损 |
| 仙元枯竭 | 能量耗尽 |
| 神魂动荡 | 精神受创 |
| 意识涣散 | 失去意识前的状态 |
