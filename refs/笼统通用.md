# 笼统通用词 分诊指南

覆盖：弄 / 搞 / 整 / 做 / 来 / 去 / 处理

---

## 核心说明

这类词本身不是问题，问题是**写的时候没想清楚动作是什么**。  
不要直接替换——先确认动作，再找对应词库文件。

---

## 分诊流程

遇到"弄""搞""整""做""处理"等词，按以下步骤处理：

**第一步：他在操作什么对象？**

| 对象类型 | 跳转 |
|---------|------|
| 用手拿、放、递、交 | → [手部-接触.md](手部-接触.md) |
| 用手抓、推、拉、砸、打 | → [手部-施力.md](手部-施力.md) |
| 用手做精细动作（写、翻、划、摸） | → [手部-精细.md](手部-精细.md) |
| 移动身体 | → [移动-步行.md](移动-步行.md) 或 [移动-姿态.md](移动-姿态.md) |
| 说话 | → [言语.md](言语.md) |
| 看 | → [视线.md](视线.md) |

**第二步：如果对象仍然不清晰，直接问作者：**

> 「他在'弄'什么？是拿起来？还是移动位置？还是修理/制作？」

**第三步：如果是抽象动作（处理事情、搞定关系）**，这类词通常是叙述层面的概括，不是场景里的具体动作，不在本词库范围内——保留原词即可，或改写成具体事件。

---

## 常见误用对照

| 原句示例 | 问题 | 处理方向 |
|---------|------|---------|
| 他把东西弄走了 | "弄走"不知道怎么移动 | 拿走？拖走？推走？→ 手部-接触或施力 |
| 她把头发整了整 | 整理头发，属精细动作 | 拢、捋、别、挽 → 手部-精细 |
| 他搞了半天 | 时间副词+笼统词，整句需重写 | 先问动作，再重写 |
| 他去做了个动作 | 双重笼统 | 直接写动作 |
