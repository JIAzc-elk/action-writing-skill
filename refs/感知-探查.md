# 感知·探查 词库

覆盖：视觉感知 / 神识探查 / 其他感官 / 锁定目标

> 感知动词是玄幻写作里"信息差"的主要载体。谁先感知到，谁占先机。

---

## 视觉感知

| 候选词 | 特征 | 情绪倾向 |
|------|------|---------|
| 扫视 | 快速大范围 | 警惕、掌控 |
| 打量 | 有评判的审视 | 怀疑、评估 |
| 观察 | 持续留意 | 中性、专业 |
| 端详 | 近距离仔细看 | 专注、欣赏 |
| 凝视 | 聚焦单点 | 专注、迷恋 |
| 注视 | 有意识地看 | 认真 |
| 遥望 | 远距离看 | 期待、落寞 |
| 望去 | 转向看 | 中性过渡 |
| 收回目光 | 结束注视 | 克制、决定 |
| 瞥 | 极短时间 | 轻描淡写 |
| 瞳孔一缩 | 受到冲击的视觉反应 | 惊讶、危险感知 |
| 目光闪动 | 视线变化 | 心思变动 |
| 眼神一凝 | 目光突然聚焦 | 警觉、发现 |

| 候选词 | 特征 | 适用场景 |

| 锁定 | 确定并标记目标 | 攻击前置 |

## 信息差的写法

感知动词最大的价值是制造"读者比某角色知道更多"或"某角色比其他人知道更多"的落差。

**读者随主角感知**：

> 他神识一扫，对方袖中有异物。对方浑然未觉他已看破。

**感知受阻，制造悬念**：

> 神识探出，半途遇阻——对方布有屏蔽阵法。

**感知触发决策**：

> 瞳孔微缩。那道气息——是死蛊的味道。  
> 他已明白了。
