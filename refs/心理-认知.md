# 心理·认知 词库

覆盖：思维流转 / 领悟判断 / 警觉戒备 / 决策意志

> 蛊真人的主战场。心理动词和外部动作是同级句子，不是括号里的注释。

---

## 核心原则

心理动作不是"内心独白"，是**可见的思维动作**。  
"心念电转"和"跨出一步"同级，同样推进节奏。  
写法：短句、前置、不解释结论。

❌ 他想了想，觉得对方可能在骗自己，于是决定先试探一下。  
✅ 心念一转。此人话中有话。  
✅ 他决意试探。

## 静态专注词（替代"打坐/盘膝"）

玄幻里的修炼状态少用"打坐""盘膝"，实际语料里这类词极低频。常用替代：

| 候选词 | 含义 |
|------|------|
| 闭目 | 合上眼睛，进入专注状态 |
| 凝神 | 精神高度集中 |
| 沉吟 | 低头思考，有时带轻声 |
| 静心 | 平复心绪 |
| 入定 | 进入深度专注（偏佛道） |

## 心理动词写法

**"一"字瞬时句**，插在动作之间切分节奏：

> 心念一沉。  
> 目光一凝。  
> 念头一转。

**直接给结论，不写推导过程**：

> ❌ 他思考了一下，分析了对方的行动规律，终于得出结论——对方在拖延时间。  
> ✅ 他已看出来了。对方在拖延。

**心理动作和外部动作交替**，制造"算计感"：

> 他负手立定。（外部）  
> 心念电转，已猜出三分。（心理）  
> 抬手，一指。（外部）
