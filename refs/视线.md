# 视线 词库

覆盖：看 / 瞧 / 瞄 / 盯 / 望 / 瞥 / 注意

---

## 看

**原词问题**：没有方向感（远近高低）、没有时长、没有情绪、没有主被动。

| 候选词 | 时长 | 方向/距离 | 情绪倾向 | 慎用情形 |
|------|------|---------|---------|---------|
| 瞥 | 极短 | 任意方向 | 轻描淡写、不经意、刻意漠视 | 时间过长时违和 |
| 扫视 | 短 | 大范围横扫 | 警惕、掌控感、审视 | |
| 打量 | 中 | 上下审视 | 审视、怀疑、评判 | |
| 端详 | 长 | 近距离仔细 | 欣赏、好奇、专注 | |
| 凝视 | 长 | 单点聚焦 | 专注、迷恋、沉思 | |
| 注视 | 中长 | 有意识地看 | 认真、关注 | 偏书面 |
| 盯 | 长 | 锁定不移开 | 紧张、愤怒、威压、执念 | |
| 瞪 | 中 | 睁大眼锁定 | 愤怒、震惊、不可置信 | |
| 睨 | 中 | 斜眼 | 轻蔑、不屑 | |
| 斜睨 | 中 | 斜眼带态度 | 嘲讽、傲慢 | |

| 环视 | 短 | 环绕一圈 | 警惕、掌控、寻找 | |
| 望 | 长 | 远处 | 思念、期盼、落寞 | 近距离时违和 |
| 仰望 | 长 | 向上 | 崇敬、渺小感、期盼 | |
| 俯视 | 中 | 向下 | 权威、怜悯、轻蔑 | |

## 特殊用法说明

**"看了一眼"** 通常是笼统写法，可拆为：
- 对象 + 视线词 + 时长/动作停顿

例：他在门口停了一下，往里扫了一眼，没进去。

**视线与头部动作的配合**：
- 低头看 → 低头打量
- 抬头看 → 抬眼（偏克制）/ 仰头（幅度大）
- 偏头看 → 侧过脸端详

**视线作为情绪出口**：  
当人物需要隐藏情绪时，视线往往是唯一泄露的地方。  
例：他一直没看她，把杯子摆了又摆。
