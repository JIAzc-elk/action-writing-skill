# 声响·生理反应 词库

覆盖：咆哮啸叫 / 拟声词 / 微动作（一愣/一震类） / 生理应激反应

> 两类词合在一个文件，因为都是**节奏调节器**：  
> 声响给场面加听觉维度；微动作在长段里制造停顿点。

---

## 一、声响 / 啸叫

和"言语.md"的区别：言语是有内容的话；这里是**无意义或情绪性发声**。

### 爆发性发声（由强到弱）

| 候选词 | 音量/程度 | 情绪倾向 |
|------|---------|---------|
| 咆哮 | 极大 | 失控的愤怒 |
| 怒吼 | 极大 | 愤怒 |
| 嘶吼 | 极大 | 绝望或拼命 |
| 大喝 | 大 | 威压、喝止 |
| 低吼 | 中 | 克制的愤怒或威胁 |
| 厉喝 | 大 | 严厉命令 |
| 长啸 | 中大 | 豪迈、得意、玄幻常见 |
| 惊呼 | 中 | 意外、惊吓 |
| 惨叫 | 中大 | 受创、恐惧 |
| 嘶叫 | 中 | 尖锐的惊叫 |
| 闷哼 | 低 | 受击后压抑的声音 |

### 拟声词（节奏感极强，少用则灵）

| 拟声词 | 场景 |
|------|------|
| 轰 / 轰隆 | 重击、爆炸 |
| 嗡 | 法术聚集、蓄力 |
| 啪 | 清脆打击 |
| 咔 / 咔嚓 | 断裂、骨折 |
| 嗤 | 利器入肉 |
| 嘶 | 气流、烧灼 |
| 砰 | 钝击、坠落 |
| 轰轰轰 | 连续重击 |

> 拟声词独立成句效果最强：「轰。地面裂开。」

## 二、生理微动作（切节奏的主力工具）

这类词独立成句，插在动作序列之间，制造停顿感。  
蛊真人靠它们拆分长段，避免动作堆砌。

### "一+动"瞬时反应

| 词 | 触发感 | 情绪 |
|---|------|------|
| 一愣 | 认知停顿 | 意外、困惑 |
| 一震 | 受到冲击 | 惊吓或感受到威压 |
| 一颤 | 细微颤动 | 恐惧、克制的激动 |
| 一缩 | 收缩回来 | 本能防御、疼痛 |
| 一滞 | 动作卡住 | 迟疑、被卡住 |
| 一顿 | 停一下 | 迟疑、发现异常 |
| 一沉 | 向下压 | 心情变重、感到压力 |
| 一紧 | 收紧 | 警觉、紧张 |
| 一凉 | 寒意 | 恐惧、预感 |
| 一热 | 热意 | 激动、受伤出血 |
| 一跳 | 心脏跳动 | 心跳加速，意外 |

---

### 生理应激反应

| 候选词 | 触发 | 情绪倾向 |
|------|------|---------|
| 咬牙 | 痛苦、克制、愤怒 | 高频，慎过度使用 |
| 倒抽一口冷气 | 惊吓、疼痛 | 通用 |
| 青筋暴起 | 极度愤怒或用力 | 外显的激动 |
| 汗毛倒竖 | 本能危险感知 | 恐惧 |
| 脸色骤变 | 信息击中要害 | 克制被破 |
| 脸色如常 | 刻意维持 | 高手感 |
| 心头一跳 | 意识到异常 | 警觉 |
| 心头一紧 | 预感到危险 | 焦虑 |
| 心头一沉 | 坏消息落地 | 压抑 |
| 气血翻涌 | 受重击内伤 | 玄幻常用 |
| 神念一震 | 精神受到冲击 | 玄幻 |
| 脑中轰鸣 | 信息量过载 | 震惊 |

## 写法说明

**微动作独立成句，不跟解释**：
> ✅ 心头一沉。他已猜出来了。  
> ❌ 他感到心头一沉，因为他意识到了事情的严重性。

**声响句独立成句，加环境结果**：
> ✅ 轰。地面在他脚下炸开，碎石弹出丈余。  
> ❌ 他发出了一声轰的巨响。

**咬牙使用频率警告**：咬牙是中文小说里滥用最严重的生理动作之一，一页内不超过一次。替代词：握拳、指节泛白、喉咙发紧。
