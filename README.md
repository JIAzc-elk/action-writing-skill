# 动作描写段落修改 skill

帮助小说作者把笼统动词改写成贴切的具体动作。适用于现代、古风、玄幻等各类小说。

## 使用方式

提供一句或一段**已有的动作描写**，同时说明：
- 想传达什么效果（情绪、意图、人物状态）
- 现有写法哪里感觉不对，或不知道怎么写

skill 会诊断问题、提问补全信息、给出 2-3 个策略不同的改写版本供选择。

## 兼容性

三端通用：Claude / Codex / OpenCode，纯 Markdown，无需任何特定工具支持。

## 设计原则

- 词库按需加载，单次只读一个文件，控制 token 消耗
- 意图策略文件比纯同义词表更重要
- 反模式清单防止改成另一种低级写法
- 每次给 2-3 个策略不同的版本，由作者挑选，不直接改稿
